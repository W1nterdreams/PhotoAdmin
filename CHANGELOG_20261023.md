# Изменения от 23.10.2026 — управление клавиатурой в поиске

- Добавлено единое скрытие экранной клавиатуры во всех поисковых полях: поиск альбомов, поиск фото внутри альбома, глобальный поиск фото и поиск альбома при копировании/перемещении.
- Тап по значку лупы или по области вне поля поиска скрывает клавиатуру, не очищая запрос.
- При начале прокрутки вне поля клавиатура закрывается, чтобы не мешать свайпу по результатам.
- Очистка запроса сохраняет фокус поля, чтобы можно было сразу ввести новый текст.
- Клавиша Enter/Search на экранной клавиатуре закрывает клавиатуру; результаты поиска обновляются по мере ввода.
- Добавлен отдельный делегированный обработчик, поэтому поведение работает и в динамически открываемых окнах.
- Версия кэша: `20261023-search-keyboard50`.
