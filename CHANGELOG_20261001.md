- Добавлен прямой пользовательский режим для личных фотоальбомов.
- Добавлен единый флаг `ALLOW_USERS` для полного включения/отключения личного режима.
- Добавлен белый список `ALLOWED_GROUP_IDS`; исходная группа `173909287` сохранена.
- Сохранена проверка управляющей роли для запуска из сообщества.
- Создание альбома теперь автоматически выбирает личный или групповой режим.
- Групповая настройка «загружать всем / только администраторам» скрывается в личном режиме и не отправляется в VK API.
- Интерфейс переведён на красно-белую цветовую систему по иконке приложения; функциональные экраны и существующие действия сохранены.
- Иконка приложения добавлена в шапку как визуальный элемент.
- Cache-busting версия обновлена до `20261001-scrollfix46`.


## scrollfix46

- Основная сетка фотографий загружает обычные страницы по 240 фото вместо 1000, поэтому при открытии альбома в DOM не создаётся сразу огромный набор карточек.
- У карточек фото убраны blur, цветная подложка, тени и анимированный scale/opacity; добавлена изоляция отрисовки off-screen карточек.
- Первые 24 превью текущей сетки загружаются приоритетно, остальные остаются lazy.
- В глобальном поиске фотографий также убраны тени/цветная подложка карточек и добавлена изоляция off-screen отрисовки.
- Обложки альбомов больше не затемняются красной вуалью и не имеют внешней тени; подпись вынесена на компактную нейтральную плашку.
- У липкой строки поиска и оверлеев убраны backdrop-filter/blur, которые заставляли WebView пересчитывать размытие во время прокрутки и появления клавиатуры.
- Редактор альбома ставит focus в поле сразу, не дожидаясь photos.getAlbums; поздний ответ VK не перезаписывает уже введённый текст.
- Редактор описания фото больше не ждёт 1–2 requestAnimationFrame перед focus.

## appidfix45

Исправлена ошибка `VKWebAppGetAuthToken: Wrong app id`. Для запроса токена теперь используется `vk_app_id` из launch-параметров текущего запуска VK. Значение `VK_APP_ID` в `js/config.js` осталось резервным fallback. Это позволяет одной сборке корректно работать при запуске в разных VK-контекстах, если фактический app id отличается от старого захардкоженного значения.
