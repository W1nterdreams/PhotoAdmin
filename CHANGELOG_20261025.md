# ФотоАдмин — 2026-10-25: неотвеченные сообщения внутри ветки

- Статус «Без ответа» рассчитывается для каждого сообщения покупателя, включая ответы внутри уже начатой ветки.
- Ответ администратора закрывает конкретное сообщение, на которое он отвечает; сам факт наличия ответа на корневой комментарий больше не скрывает отметку у последующего сообщения покупателя.
- Для веток, где VK сообщает только ID корня, связь с конкретным ответом дополнительно восстанавливается по начальному VK-упоминанию автора.
- В общей ленте комментариев, комментариях альбома и комментариях в просмотрщике фото используется согласованная логика.
- Неотвеченные ответы получают отдельную янтарную подсветку и плашку «Без ответа».
- Версия кэша ресурсов исходного исправления: `20261025-thread-unanswered51`.

## Приоритет веток без ответа

- В общей ленте, комментариях альбома и комментариях фотографии ветки с хотя бы одним неотвеченным сообщением покупателя показываются выше отвеченных.
- Внутри каждой группы ветки сортируются по времени последней активности: самые свежие выше.
- Порядок сообщений внутри ветки сохраняется хронологическим.
- Версия кэша ресурсов: `20261025-unanswered-priority52`.

## Исправление определения автора ответа

- Ответы от других администраторов теперь не получают плашку «Без ответа» только потому, что автор ответа не является пользователем, открывшим мини-приложение.
- Внутри обычной ветки покупателем считается автор исходного сообщения; ответ от другого автора закрывает только тот комментарий, на который он непосредственно ответил.
- Если покупатель пишет повторно в той же ветке, его новое сообщение снова помечается как неотвеченное до следующего ответа администратора.
- Общая лента, комментарии альбома и просмотрщик фотографии используют один общий модуль статусов.
- Версия кэша ресурсов: `20261025-unanswered-fix53`.
